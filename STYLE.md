# Style guide for generated code

* At most 100 characters per line
* No trailing semicolons
* No spaces before semicolons (so ` ; ` should be changed to `; `)
* No unnecessary spaces around parentheses, square brackets, curly braces and angle brackets
* Options for tactics, such as `+decide` and `+zetaDelta` for `simp`, should be suppressed whenever they are unnecessary
* Dot notation should be used where possible
