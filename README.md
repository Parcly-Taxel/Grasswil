# Grasswil – an Aristotle-aided formalisation of convex polytope theory

This is my working folder for the `platonic_classification` lean-eval task. Most of the code was generated with the help of Aristotle, but all of it has been reviewed by me (a human).

Grasswil (now part of Seeberg in the canton of Bern) was the birthplace of Ludwig Schläfli.
